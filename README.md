# Viajes Aventura

Sistema de gestión para la agencia **Viajes Aventura**, desarrollado en Python con arquitectura por capas (presentación, lógica de negocio y persistencia)[cite: 2, 9].

## Estructura del proyecto

* `docs/`: Requerimientos y diseño de la base de datos.
* `src/presentation/`: Pantallas y mensajes que ve el usuario (en español).
* `src/business/`: Reglas y cálculos del negocio[cite: 9].
* `src/persistence/`: Conexión y consultas a la base de datos[cite: 9].
* `main.py`: Archivo principal para ejecutar el programa y probar la conexión.
